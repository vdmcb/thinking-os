# Understand skill: review findings and plan (2026-08-28)

Source of the findings: a blind trial of three summary formats on four private documents (a performance report, a methodology paper, a migration proposal, and a product briefing). The three-stakeholder-questions format (state / decision / resources) was picked 4 of 4. Nine independent audit rounds over the trial and its predecessor produced the truth rules below. The trial page and documents are not committed.

## Verdict

The skill in this working tree (v2.0.0) is already in the right shape: scoped stance, Q1/Q2/Q3, verbatim quotes, causal-verb rule, "Not stated" discipline, audit pass, `Audited:` line, three follow-up questions. Do not rebuild it. Fix what is around it.

## Findings, ranked by consequence

1. **Not installed.** `~/.claude/skills/understand` is v1.1.0 (old packet format, `references/core/` layout). v2.0.0 is uncommitted; last commit is "Initial commit". `/understand` on this machine runs the rejected format.
2. **Audit is optional.** SKILL.md step 9 lets a self-audit stand in for the independent agent. In every audit round, self-review missed the dropped-qualifier class; the independent agent caught it every time, including a reversed causal verb ("closes 72% of the gap" written as "accounted for 72%") that survived three passes. The skill ships no audit prompt.
3. **Three rules missing.** No rule against evaluative adjectives standing in for the stance ("invalid", "proven", "fine"); no rule against calling an option "current" or "in production" unless the source does; no rule that a source's "recommends" stays a recommendation, not a mandate. Auditors flagged each of these in the trial.
4. **Docs drift.** `evals/understand/STATUS.md` describes "format v3" memo prose with a "Questions for the author" header; SKILL.md, exemplars 14/15 and `scripts/check-evals.py` use Q1/Q2/Q3 + "Follow-up questions". `expected-invariants.json` lists the optional reference-analysis headers under `required_sections`.
5. **Rule conflict.** `human-voice.md` bans en dashes in ranges; the contract requires verbatim quotation, and sources write "7–8 hour". Precedence is not stated.
6. **PDF guidance incomplete.** Only `pdftotext -layout` is mandated. On a two-column PDF it interleaved columns mid-sentence; plain `pdftotext` read them in order. No rule for a source that is itself clipped (browser-print PDFs).

Leave alone: the three follow-up questions (trial winner had none, user picked it anyway; keep, watch the 600-word ceiling); step 5 first-principles reduction (internal, never printed; cut only if evals show no effect).

## Truth rules that survived nine audits

Carry every qualifier and scope word from the source. Carry causal verbs verbatim; check direction of effect for every figure next to a verb. Quotation marks mean verbatim. Where the source is silent write "Not stated"; never borrow an answer from a different step or section. Do not resolve the source's ambiguities. Show arithmetic beside raw figures with the source's own wording. The stance is a label on a named object; adjectives do not carry it. An independent auditor finds what the author cannot.
